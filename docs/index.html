Ozellikler //

🔍

Otomatik Etiketleme

Klasör içindeki dosyalara bakarak proje, araç, belge, medya gibi etiketleri otomatik atar.

⚡

Arka Plan Tarama

QThread ile tarama UI'yi dondurmadan arka planda yürür; büyük dizinlerde bile akıcı çalışır.

💾

Kalici Kayit

Etiketler ~/.disk_index.json dosyasına kaydedilir. Hiçbir dosya taşınmaz veya silinmez.

🌏

Platformlar Arasi

Windows, macOS ve Linux üzerinde çalışır. Explorer / Finder / xdg-open ile klasör açma desteği.

Etiket Turleri //

Proje
.git, requirements.txt, package.json, main.py vb. içeren klasörler
Arac
installer, setup, .exe / .msi barındıran klasörler
Belge
.pdf, .docx, .xlsx, .md ve diğer belge uzantıları
Medya
Resim, video, ses — .mp4, .jpg, .mp3 vb.
Zip / Arsiv
.zip, .rar, .7z, .tar.gz ve diğer arşiv formatları
Cop
Manuel olarak işaretleyebileceğin öğeler
